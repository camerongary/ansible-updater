✅ HOW TO USE THESE FILES
────────────────────────────────────────────────────────────────

1. Download all files from this directory

2. Upload to Docker server (192.168.12.104):
   scp -r * root@192.168.12.104:/root/ansible-updater/

3. SSH to Docker server:
   ssh root@192.168.12.104

4. Read the setup guide:
   cat DOCKER_SERVER_SETUP.md

5. Setup SSH keys to target servers:
   ssh-copy-id -i ~/.ssh/id_rsa root@192.168.12.10
   ssh-copy-id -i ~/.ssh/id_rsa root@192.168.12.11
   # ... repeat for all targets

6. Deploy:
   docker-compose build
   docker-compose up -d

7. Monitor:
   docker-compose logs -f

8. Check Slack workspace for messages!
