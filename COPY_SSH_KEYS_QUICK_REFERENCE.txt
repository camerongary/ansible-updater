💡 KEY FEATURES

✅ RETRY LOGIC: Tries 3 times per server before giving up
   • This is because SSH sometimes takes a moment to accept connections

✅ INTERACTIVE FALLBACK: If automatic copy fails, asks for password
   • Runs: ssh-copy-id interactively
   • You type the server password
   • Key gets copied

✅ VERIFICATION: After copying, tests that SSH works
   • Confirms keys were actually installed correctly
   • Runs: ssh -i key root@ip "echo ok"

✅ PRE-FLIGHT CHECKS: Verifies everything is installed first
   • SSH key exists
   • nmap installed
   • ssh-copy-id available
   • Stops if anything is missing
