# SSH Key Distribution - Quick Start

## 🚀 What You Have

Your system now includes **automatic SSH key distribution** to all discovered servers!

### Three Methods Available:

1. **Standalone Script** (Manual, anytime)
2. **Docker Integrated** (Automatic on startup)
3. **Manual** (ssh-copy-id commands)

---

## Method 1: Standalone Script (Easiest)

### On Docker Server (192.168.12.104):

```bash
# 1. Navigate to project
cd /root/ansible-updater

# 2. Run the SSH key copy script
bash copy-ssh-keys.sh

# That's it! The script will:
# ✓ Discover all servers in 192.168.12.0/24
# ✓ Copy SSH key to each one
# ✓ Verify SSH access works
# ✓ Show summary report
```

### What It Does:

```
1. Checks prerequisites (SSH key, nmap, ssh-copy-id)
2. Discovers servers via nmap (finds all live hosts)
3. Copies SSH key to each server (with retries)
4. Tests SSH access on each server
5. Shows detailed report
```

## Method 2: Docker Integrated (Automatic)

### Option A: Environment Variable

```bash
# Start with automatic SSH key setup
SSH_KEY_SETUP=true docker-compose up -d

# Watch progress
docker-compose logs -f
```

### Option B: Add to .env

```bash
# Edit .env file
echo "SSH_KEY_SETUP=true" >> .env

# Then start normally
docker-compose up -d
docker-compose logs -f
```

### What Happens:

1. Container starts
2. Discovers all servers in 192.168.12.0/24
3. Automatically copies SSH key to each one
4. After successful setup, exits and waits for you to restart
5. Then runs normal update cycles

## Method 3: Manual Commands

If you prefer to do it manually:

```bash
# On Docker server (192.168.12.104):

# 1. Generate SSH key (if you don't have one)
ssh-keygen -t ed25519 -f ~/.ssh/id_rsa -N ""

# 2. Copy to each server manually
ssh-copy-id -i ~/.ssh/id_rsa root@192.168.12.10
ssh-copy-id -i ~/.ssh/id_rsa root@192.168.12.11
ssh-copy-id -i ~/.ssh/id_rsa root@192.168.12.15
ssh-copy-id -i ~/.ssh/id_rsa root@192.168.12.20
ssh-copy-id -i ~/.ssh/id_rsa root@192.168.12.25

# 3. Verify (should not ask for password)
ssh -i ~/.ssh/id_rsa root@192.168.12.10 "echo OK"
```

## Troubleshooting

### SSH Key Not Found

```bash
# Generate SSH key
ssh-keygen -t ed25519 -f ~/.ssh/id_rsa -N ""

# Verify
ls -la ~/.ssh/id_rsa
```

### nmap Not Installed

```bash
# On Ubuntu/Debian
sudo apt-get install nmap

# On CentOS/RHEL
sudo dnf install nmap
```

### Some Servers Fail to Copy Key

The script has **retry logic** and **interactive mode**:

```
⚠ Could not copy SSH key to 192.168.12.10 automatically
Would you like to try interactive copy? (y/n) y

# Then enter password when prompted
```

Or do it manually:

```bash
ssh-copy-id -i ~/.ssh/id_rsa root@192.168.12.10
```

### Verify SSH Works

```bash
# Test on one server
ssh -i ~/.ssh/id_rsa root@192.168.12.10 "echo OK"

# Should output: OK
# Should NOT ask for password
```

## Environment Variables (Advanced)

```bash
# Control behavior via environment variables:

SSH_KEY_SETUP=true          # Enable automatic setup
SSH_USER=root               # SSH username (default: root)
SSH_KEY=/root/.ssh/id_rsa   # SSH key path (default: ~/.ssh/id_rsa)
NETWORK_RANGE=192.168.12.0/24  # Network to scan

# Example:
SSH_KEY_SETUP=true SSH_USER=ubuntu docker-compose up -d
```
